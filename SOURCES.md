## Notes

All source data referenced above was obtained from publicly available sources.

This repository evaluates infrastructure associated with publicly funded broadband programs. Consistent with the public nature of both the source information and the funding involved, the resulting dataset, methodology, and analysis are being released publicly for use by residents, researchers, journalists, local governments, and other interested parties.

Users should independently verify source data and understand that updates to the original source datasets may occur after publication of this repository.
